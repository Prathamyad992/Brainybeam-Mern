# Pratham Yadav Portfolio

A responsive personal portfolio website created to showcase Pratham Yadav's profile, skills, and projects.

## Project Overview

This is a frontend portfolio website built using plain HTML, CSS, and JavaScript. It includes personal information, technical skills, projects, and a contact form.

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, colors, responsive design, and media queries
- **JavaScript** – Mobile navigation menu and contact form validation

> Java, XML, Firebase, and MERN Stack are not used to build this portfolio website. They are mentioned only in the project descriptions.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `Portfolio.html` in any web browser.

For live preview, install the **Live Server** extension in Visual Studio Code and open `Portfolio.html` with Live Server.

## Responsive Design

The website is responsive and supports:

- Desktop screens
- Tablet screens
- Mobile screens

CSS media queries adjust the navigation menu, skills layout, project layout, and heading sizes for smaller screens.

## Current Limitations

- Contact form is not connected to a backend.
- GitHub and Live Demo buttons currently contain placeholder links.
- No external database or API is connected.
- No Java or MERN Stack code is included in this portfolio repository.
